# KlyroStream frontend

Next.js (App Router) + TypeScript + Tailwind v4 + shadcn/ui (Radix base, Nova preset).

## Folder structure

```
src/
  app/                  routes only: page.tsx / layout.tsx stay thin and render a screen
  components/
    ui/                 shadcn components, generated by the CLI or the shadcn MCP. Never edit.
    common/             app-wide components built on top of ui/ (e.g. LoaderButton wraps Button)
    screens/<screen>/   components used by one screen only (e.g. screens/login/login-form.tsx)
  lib/                  utilities (cn, api client, ...)
  hooks/                shared hooks
```

## Rules

- `src/components/ui` is owned by shadcn. Do not modify those files. Add new ones with
  `npx shadcn@latest add <name>` (or the shadcn MCP). If a variant or behaviour is missing,
  compose a new component in `common/` that wraps the ui primitive and passes props through.
- A component used by a single screen lives in `screens/<screen>/`. Promote it to `common/` once a
  second screen needs it.
- Files are kebab-case (`loader-button.tsx`), components are PascalCase named exports.
- Dev server runs on port 5173 (the backend's `FRONTEND_URL`, OAuth redirect and email links point there).
- `npm run check` runs typecheck, lint and prettier.
